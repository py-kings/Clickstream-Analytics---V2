01 — Ingestion

The event simulator produces e-commerce clickstream events into an Apache Kafka topic.

02 — Bronze Layer

PySpark Structured Streaming reads Kafka events, parses the JSON payload, generates event IDs, applies watermarking and removes duplicate events.

03 — Silver Layer

The Silver layer performs timestamp conversion, data cleaning, enrichment and data-quality processing before persistence.

04 — Gold Layer

Gold processing performs 30-minute inactivity sessionization and generates session-level and daily funnel analytics.

05 — Orchestration

Apache Airflow orchestrates the bounded Bronze → Silver processing followed by the Gold batch transformation.

06 — Analytics

Power BI consumes exported analytical data to visualize traffic, cart activity, transactions, conversion and product performance.

Technology Stack
Python · PySpark · Apache Kafka · Delta Lake · Apache Airflow · Docker · Power BI
